# MediPortal Enterprise CHANGELOG

All notable changes to the MediPortal Enterprise ecosystem will be documented in this file.

## [2.0.0] - 2026-05-14 (Global Release)
### Phase 10: Intelligence Unified
- **Executive Command Center**: Unified dashboard aggregating Clinical AI, Operational Forecasting, Genomic Insights, and Financial RPA.
- **RPA Auto-Claims**: Implemented an AI-driven "Claim Scrubber" and adjudication engine to automate insurance settlements.
- **Precision Medicine**: Launched the Genetic Data Vault with Pharmacogenomic Shielding to prevent adverse drug reactions.
- **Predictive Operations**: Real-time bed occupancy forecasting using Gemini-powered time-series analysis.
- **Production Hardening**: Swagger Documentation v2.0, Optimized Pino logging, and hardened Docker orchestrations.

## [1.5.0] - 2026-04-30
### Phase 8-9: Interoperability & Mobile
- **FHIR Integration**: Full support for HL7 FHIR R4 resources for patient data exchange.
- **Mobile Patient App**: Launched iOS/Android mobile patient portal for appointments and records.
- **Telemedicine Core**: Integrated WebRTC for high-definition clinical consultations.

## [1.0.0] - 2026-04-15
### Phase 1-7: Foundation & Core EHR
- **Core EHR**: Implemented Vitals, Clinical Notes, Prescriptions, and Lab Management.
- **Billing & Finance**: Multi-tenant billing engine with GST/tax support and offline/online payment channels.
- **Multi-Tenant Architecture**: Robust branch-based isolation and role-based access control (RBAC).
- **AI Triage**: First iteration of the Gemini-powered symptom triage engine.
